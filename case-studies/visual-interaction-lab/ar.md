# مختبر التفاعل البصري

[العربية](ar.md) · [English](en.md) · [Türkçe](tr.md)

**مرشح إصدار خاص متحقق محليًا**

## التصميم والتنفيذ

طوّرت مختبرًا على Windows لدراسة تحليل الوجه واليد من واجهة متصفح واحدة. ترسل الواجهة إطارات الصورة أو ملف الفيديو أو الكاميرا التي يفعّلها المستخدم إلى خدمة Python محلية. يكشف YuNet الوجوه، ثم يصنّف نموذج EmotiEffLib الوجه المحدد ضمن سبع فئات عبر ONNX Runtime. يعالج MediaPipe Gesture Recognizer مسار اليد، وتبقى إشارة OK تجريبية بقاعدة منفصلة تعتمد على معالم اليد. تميّز الواجهة بين إشارة غير معروفة وعدم اكتشاف يد.

## التحقق والقيود والإتاحة

تبدأ الكاميرا باختيار المستخدم وتبقى المعالجة على الجهاز. يعطّل المرشح الخاص الموثّق تحريك مؤشر Windows فعليًا ويكتفي بمعاينة داخل التطبيق. لا يتضمن الإصدار عرض مربعات لوجوه متعددة بعد إخفاق فحص الأداء، وتقييم الكمامات يفتقر إلى بيانات مستقلة. اجتاز المرشح 48 فحص Python و18 فحص Node و17 فحص Chrome آليًا. وطابق تقييم KDEF السابق 67 صورة من أصل 71 لـ12 شخصًا. تعكس الدرجات غير المعايرة فئات تعبير مرئي، ولا تثبت المشاعر أو الدقة العامة أو الأداء اللحظي أو التعافي بعد انقطاع الكاميرا ماديًا. تعرض الصفحة العامة وصف المختبر، وتظل الشيفرة والنماذج والأوزان وبيانات التدريب خاصة أو خاضعة لحقوق توزيع مستقلة.
